# todo-list-                                                                                                                                                            # 🚀 Daily Planner - Stay Productive

A modern, glassmorphism-inspired web application to manage your daily tasks and track your wellness goals.

## 📸 Preview
## ✨ Features
* **Task Management:** Add, complete, and delete tasks with a clean interface.
* **Wellness Trackers:** Log your water intake and workout minutes.
* **Responsive Design:** Works perfectly on mobile, tablet, and desktop.
* **Live Stats:** Real-time tracking of total and completed tasks.

## 🛠️ Tech Stack
* **HTML5** - Semantic structure
* **CSS3** - Custom styling & animations
* **JavaScript** - Core logic & interactivity
* **Bootstrap 5** - Layout & responsiveness
* **FontAwesome** - Modern icons
